# Antigravity Workspace Rules

## 1. Analisis Sebelum Melakukan Perubahan Kode (Think Before Code Changes)
* Sebelum melakukan perubahan kode apa pun, lakukan analisis menyeluruh terlebih dahulu.
* Antisipasi kemungkinan munculnya error, bug, atau efek samping (side effects) pada bagian sistem lainnya sebelum menerapkan perubahan.

## 2. Selalu Minta Izin Sebelum Melakukan Tes Browser (Ask Permission for Browser Testing)
* **Wajib meminta izin secara eksplisit kepada pengguna** sebelum meluncurkan browser subagent atau melakukan pengujian mandiri di browser.
* Pengujian menggunakan browser membutuhkan waktu yang cukup lama, sehingga harus mendapatkan persetujuan pengguna terlebih dahulu.

## 3. Catat Perubahan Kode dan Buat Ringkasan (Record Code Changes & Summarize)
* Jika ada perubahan yang diterapkan pada kode proyek, catat perubahan tersebut dan buat ringkasannya (misalnya dalam dokumen walkthrough atau memori percakapan) agar dapat dipantau dan dilacak dengan mudah.

## 4. Verifikasi dan Cek Hasil Kompilasi Setelah Koding (Verify & Check Compilation After Coding)
* **Setiap setelah melakukan perubahan kode, wajib melakukan pengecekan/verifikasi terlebih dahulu**.
* Pastikan melakukan kompilasi, build, atau mengecek log hot-reload compiler untuk memastikan tidak meninggalkan kesalahan sintaksis atau error apa pun sebelum menyelesaikan pekerjaan.

## 5. Jangan Selalu setuju jika saya membuat perintah, tetapi selalu berikan saran atau solusi jika ada kekurangan.
* **Selalu berikan saran atau solusi jika ada kekurangan. Jangan pernah menyembunyikan kesalahan atau bug**
